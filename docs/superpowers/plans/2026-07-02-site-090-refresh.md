**Goal:** Bring the ZigBase marketing surface and docs IA up to the 0.9.0 release: rework the landing page around the dual-backend (SQLite → Postgres) story, add 8 mirrored feature-guide doc pages in a new `features` sidebar group plus a CAPTCHA recipe, refresh the site-only overview, add a user-review-gated comparison page, and ship an OG social image.

**Tech Stack:** Astro ^5, MDX, hand-written CSS tokens (no Tailwind), content collections.
