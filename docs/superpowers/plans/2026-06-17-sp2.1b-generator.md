## Architecture

The generator is a small Zig executable built from inside zigbase's `build.zig` with two imports: `zigbase` (for `schema`/`framework` types) and `app` (the consumer's module that exposes `pub const App = zigbase.App(.{...})`). `main()`:

1. parses CLI (`--out <path>`, `--api-prefix <p>` default `/api`, `--check`),
2. reads `@import("app").App.collections` (`[]const schema.Collection`, already lowered by `provision.buildCollections` at comptime — **relation `targetCollectionId` holds the target collection NAME at this stage**, so no id→name resolution is needed),
3. runs the **generator-time guards** (operator-name invariant; identifier safety + collision),
4. drives the **emit-helpers** (one Zig fn per TS fragment) over the collections, each appending to a shared `std.ArrayList(u8)` writer, backed by a single **field → TS type mapper**,
5. computes a **schema hash** + a deterministic header, then either writes `--out` or (under `--check`) diffs the freshly-emitted buffer against the file at `--out` and exits non-zero on drift.

```
                         ┌─────────────────────────────────────────────┐
   @import("app")        │            gen_client.zig (exe main)         │
   App.collections  ───▶ │  parse CLI → read collections → guards →     │
   []const Collection    │  emit(header) → for each col: emit-helpers → │
                         │  schema hash → write | --check diff          │
                         └───────┬──────────────────┬───────────────────┘
                                 │                  │
                    ┌────────────▼───┐   ┌──────────▼────────────┐
                    │  guards.zig    │   │  emit.zig             │
                    │ operator-name  │   │ emitImports/Record/   │
                    │ identifier/    │   │ Create/Update/Where/  │
                    │ collision      │   │ Fields/Relations/     │
                    └────────┬───────┘   │ ExpandKeys/Service/   │
                             │           │ RealtimeAlias/Meta/   │
              ┌──────────────▼──┐        │ ClientFactory         │
              │ identifiers.zig │        └──────────┬────────────┘
              │ valid id, names,│                   │
              │ reserved set    │        ┌──────────▼────────────┐
              └─────────────────┘        │  ts_type.zig          │
                                         │ Field → TS type str   │
                                         └───────────────────────┘
```

`build.zig` gains `pub fn genClientStep(b, zigbase_dep, app_mod, opts) *std.Build.Step.Run` plus a repo-local `gen-dating-client` step that runs the generator against `fixtures/dating/schema.zig`, writing `clients/typescript/test/codegen/dating/zbase.gen.ts`.

## Global Constraints

- **Pure-Zig generator.** No Node anywhere in the generation path. Node (`npx tsc`/`npm test`) only typechecks and tests the emitted `.ts`.
- **Build via `mise exec zig@0.16.0 -- zig build`** — every Zig build/test/run command in this plan uses this exact prefix. Plain `zig` is 0.15.2 and will not compile this tree.
- **Output imports `@zigbase/client` + `@zigbase/client/typed`.** In the *in-repo* dating snapshot the imports resolve to the package source (`../../../src/index.js`, `../../../src/typed/index.js`) so it typechecks against the working tree without a built `dist` — exactly as `blog.gen.ts` does. A `--api-prefix`/package-import mode flag governs whether emitted import specifiers use the published subpaths or the in-repo source paths; the dating snapshot uses in-repo (see Task 4).
- **Deterministic output.** Collections, fields, type names, and consts are emitted **in declared order** (the order in `App.collections`, which is the consumer's declaration order). The header is fixed text + a **schema hash** (FNV-1a over a canonical serialization of the collections, lowercased hex). Re-running the generator on an unchanged schema produces a byte-identical file.
- **Header.** Exactly:
  ```
  // generated by zigbase — do not edit
  // schema-hash: <hex>
  ```
  followed by the same in-repo-import explanatory comment block `blog.gen.ts` carries.
- **Guards fail the build.** Both generator-time guards return a Zig error with a precise message (collection + field named). A guard failure makes `zig build gen-dating-client` (and `genClientStep`) exit non-zero — the schema never silently mis-emits.
- **Thin output over a tested core.** The generator emits only concrete types + `createClient` wiring. It never re-implements `WithExpand`, `compileWhere`, the fluent builder, `makeRecordService`, `makeTypedRealtime`, or `makeTypedFiles` — those are imported from the typed core.
- **Auth synthesis.** For `collection.type == .auth`, the generator synthesizes the **visible** system fields `email` (email), `username` (text), `verified` (bool) — `passwordHash`/`tokenKey` are `hidden` and skipped. `id`/`created`/`updated` are always present on reads. (`schema.authSystemFields()` is the canonical list; the generator filters out `hidden`.)
- **One Zig→TS mapper.** `ts_type.zig` is the single field→TS-type function reused by every emit fn.

```zig
//! Field → TypeScript type-string mapper. The single helper every emit fn reuses.
const std = @import("std");
const schema = @import("../schema.zig");
const ident = @import("identifiers.zig");

pub const TsKind = enum { string, number, boolean, unknown, select_union, relation_id, file_name };

/// The TS *kind* of a field, ignoring multiplicity. Drives guards + emit branching.
pub fn kindOf(f: schema.Field) TsKind {
    return switch (f.options) {
        .text, .email, .url, .editor, .date, .autodate => .string,
        .number => .number,
        .@"bool" => .boolean,
        .json => .unknown,
        .select => .select_union,
        .relation => .relation_id,
        .file => .file_name,
    };
}

/// The emitted union *type name* for a select field, e.g. ("posts","status") -> "PostStatus".
/// `<RecordName><FieldPascal>`. RecordName mirrors identifiers.recordName.
pub fn selectUnionName(alloc: std.mem.Allocator, col_name: []const u8, field_name: []const u8) ![]const u8 {
    const rec = try ident.recordName(alloc, col_name);
    const fp = try ident.pascal(alloc, field_name);
    return std.fmt.allocPrint(alloc, "{s}{s}", .{ rec, fp });
}

/// The scalar (element) TS type of a field — the operand domain for where/fields.
pub fn tsBaseTypeOf(alloc: std.mem.Allocator, col_name: []const u8, f: schema.Field) ![]const u8 {
    return switch (kindOf(f)) {
        .string, .relation_id, .file_name => "string",
        .number => "number",
        .boolean => "boolean",
        .unknown => "unknown",
        .select_union => try selectUnionName(alloc, col_name, f.name),
    };
}

/// The record/value TS type of a field — `[]` appended when the field is multi-value.
pub fn tsTypeOf(alloc: std.mem.Allocator, col_name: []const u8, f: schema.Field) ![]const u8 {
    const base = try tsBaseTypeOf(alloc, col_name, f);
    if (f.isMultiValue()) return std.fmt.allocPrint(alloc, "{s}[]", .{base});
    return base;
}
```

## Task 3: Identifiers + the two generator-time guards

`identifiers.zig` provides name validity, the reserved/imported-name set, and the canonical name derivations. `guards.zig` provides the two invariants that fail the build with precise messages.

**Interfaces**
- Consumes: `schema.Collection`, `schema.Field`, `schema.isValidIdentifier` (reused — same identifier rule the engine enforces), `ts_type.kindOf`, `schema.authSystemFields`.
- Produces (identifiers.zig):
  - `pub fn pascal(alloc, s) ![]const u8` — PascalCase a snake/lower name (`"sentAt"`→`"SentAt"`, `"photos"`→`"Photos"`, `"profiles"`→`"Profiles"`).
  - `pub fn recordName(alloc, col_name) ![]const u8` — the singular-ish record type name. Rule: PascalCase the collection name, then strip a trailing `s` if present (`"profiles"`→`"Profile"`, `"photos"`→`"Photo"`, `"tags"`→`"Tag"`, `"messages"`→`"Message"`, `"winks"`→`"Wink"`, `"subscriptions"`→`"Subscription"`). Matches `blog.gen.ts` (`users`→`User`, `posts`→`Post`, `tags`→`Tag`).
  - `pub fn whereName/createName/updateName/relationsName/expandName/fieldsName/realtimeAliasName(alloc, col_name)` — `<Record>Where`, `<Record>Create`, etc.
  - `pub fn serviceName(alloc, col_name)` — PascalCase(collection)+`"Service"` (NOTE: uses the **plural** collection name: `posts`→`PostsService`, `profiles`→`ProfilesService` — matches `blog.gen.ts`).
  - `pub fn metaConst(alloc, col_name)` — `<colCamel>Meta` (e.g. `postsMeta`, `profilesMeta`).
  - `pub fn isValidTsIdent(s) bool` — TS identifier rule (reuse `schema.isValidIdentifier`: letter-start, alnum/underscore; sufficient for collection/field names).
  - `pub fn isReservedName(name) bool` — collides with a typed-core import/reserved name.
- Produces (guards.zig):
  - `pub const GuardError = error{ OperatorNameClash, InvalidIdentifier, NameCollision, OutOfMemory };`
  - `pub fn checkOperatorNames(alloc, cols) GuardError!void`
  - `pub fn checkIdentifiers(alloc, cols) GuardError!void`
  - both return an allocated `last_error_message` via a `pub var` or an out-param; the plan uses an out-param struct (`pub const GuardReport = struct { message: []const u8 };`) so `main()` can print it.

```zig
//! TS identifier validity, the reserved/imported-name set, and name derivations.
const std = @import("std");
const schema = @import("../schema.zig");

/// PascalCase a name: uppercase the first char, drop separators ('_','-') and
/// uppercase the char that follows. camelCase humps are preserved (sentAt -> SentAt).
pub fn pascal(alloc: std.mem.Allocator, s: []const u8) ![]const u8 {
    var out: std.ArrayList(u8) = .empty;
    var upper_next = true;
    for (s) |ch| {
        if (ch == '_' or ch == '-') {
            upper_next = true;
            continue;
        }
        if (upper_next) {
            try out.append(alloc, std.ascii.toUpper(ch));
            upper_next = false;
        } else {
            try out.append(alloc, ch);
        }
    }
    return out.toOwnedSlice(alloc);
}

/// Lower-case the first char of a name (for `<name>Meta` consts).
fn camelFirst(alloc: std.mem.Allocator, s: []const u8) ![]const u8 {
    if (s.len == 0) return alloc.dupe(u8, s);
    const out = try alloc.dupe(u8, s);
    out[0] = std.ascii.toLower(out[0]);
    return out;
}

/// The record type name: PascalCase(collection), trailing 's' stripped (simple
/// singularization matching blog.gen.ts: users->User, posts->Post, tags->Tag).
pub fn recordName(alloc: std.mem.Allocator, col_name: []const u8) ![]const u8 {
    const p = try pascal(alloc, col_name);
    if (p.len > 1 and p[p.len - 1] == 's') return p[0 .. p.len - 1];
    return p;
}
```

```zig
//! Generator-time invariants. Each returns a precise message via `GuardReport`
//! and fails the build, so a bad schema never silently mis-emits.
const std = @import("std");
const schema = @import("../schema.zig");
const ident = @import("identifiers.zig");

pub const GuardError = error{ OperatorNameClash, InvalidIdentifier, NameCollision, OutOfMemory };

pub const GuardReport = struct { message: []const u8 };

/// where-operator keys. A relation-TARGET collection must not have a field named
/// like one of these, else the where-DSL's nested-relation-vs-id-operator
/// disambiguation is ambiguous (see compileWhere's documented invariant).
const OPERATOR_KEYS = [_][]const u8{ "eq", "neq", "gt", "gte", "lt", "lte", "like", "nlike", "in", "AND", "OR" };

fn isOperatorKey(name: []const u8) bool {
    for (OPERATOR_KEYS) |k| if (std.mem.eql(u8, name, k)) return true;
    return false;
}

fn findByName(cols: []const schema.Collection, name: []const u8) ?schema.Collection {
    for (cols) |c| if (std.mem.eql(u8, c.name, name)) return c;
    return null;
}

/// Guard 1: any collection that is the TARGET of a relation must not own a field
/// whose name is a where-operator key.
pub fn checkOperatorNames(alloc: std.mem.Allocator, cols: []const schema.Collection, report: *GuardReport) GuardError!void {
    for (cols) |c| {
        for (c.fields) |f| {
            if (f.options != .relation) continue;
            const target = findByName(cols, f.options.relation.targetCollectionId) orelse continue;
            for (target.fields) |tf| {
                if (isOperatorKey(tf.name)) {
                    report.message = try std.fmt.allocPrint(alloc,
                        "codegen: collection '{s}' field '{s}' relates to '{s}', which has a field '{s}' named like a where-operator — this makes the nested-relation where ambiguous. Rename '{s}.{s}'.",
                        .{ c.name, f.name, target.name, tf.name, target.name, tf.name });
                    return GuardError.OperatorNameClash;
                }
            }
        }
    }
}

/// Append every generated type/const name a collection produces to `seen`, erroring
/// on an invalid identifier, a reserved-name collision, or a duplicate.
fn registerName(alloc: std.mem.Allocator, seen: *std.ArrayList([]const u8), name: []const u8, owner: []const u8, report: *GuardReport) GuardError!void {
    if (!ident.isValidTsIdent(name)) {
        report.message = try std.fmt.allocPrint(alloc, "codegen: '{s}' (from collection '{s}') is not a valid TS identifier.", .{ name, owner });
        return GuardError.InvalidIdentifier;
    }
    if (ident.isReservedName(name)) {
        report.message = try std.fmt.allocPrint(alloc, "codegen: generated name '{s}' (from collection '{s}') collides with a reserved typed-core name.", .{ name, owner });
        return GuardError.NameCollision;
    }
    for (seen.items) |s| if (std.mem.eql(u8, s, name)) {
        report.message = try std.fmt.allocPrint(alloc, "codegen: generated name '{s}' (from collection '{s}') collides with another generated name.", .{ name, owner });
        return GuardError.NameCollision;
    };
    try seen.append(alloc, name);
}

/// Guard 2: every collection/field name yields a valid TS identifier, and every
/// generated type name is mutually unique + not reserved.
pub fn checkIdentifiers(alloc: std.mem.Allocator, cols: []const schema.Collection, report: *GuardReport) GuardError!void {
    var seen: std.ArrayList([]const u8) = .empty;
    for (cols) |c| {
        if (!ident.isValidTsIdent(c.name)) {
            report.message = try std.fmt.allocPrint(alloc, "codegen: collection name '{s}' is not a valid TS identifier.", .{c.name});
            return GuardError.InvalidIdentifier;
        }
        for (c.fields) |f| {
            if (!ident.isValidTsIdent(f.name)) {
                report.message = try std.fmt.allocPrint(alloc, "codegen: field '{s}' in collection '{s}' is not a valid TS identifier.", .{ f.name, c.name });
                return GuardError.InvalidIdentifier;
            }
        }
        // Register each top-level generated NAME (record/where/create/update/
        // relations/expand/fields/service). Select-union names are scoped per-field
        // and registered too (they are exported types).
        try registerName(alloc, &seen, try ident.recordName(alloc, c.name), c.name, report);
        try registerName(alloc, &seen, try ident.whereName(alloc, c.name), c.name, report);
        try registerName(alloc, &seen, try ident.createName(alloc, c.name), c.name, report);
        try registerName(alloc, &seen, try ident.updateName(alloc, c.name), c.name, report);
        try registerName(alloc, &seen, try ident.relationsName(alloc, c.name), c.name, report);
        try registerName(alloc, &seen, try ident.expandName(alloc, c.name), c.name, report);
        try registerName(alloc, &seen, try ident.fieldsName(alloc, c.name), c.name, report);
        try registerName(alloc, &seen, try ident.serviceName(alloc, c.name), c.name, report);
        try registerName(alloc, &seen, try ident.realtimeAliasName(alloc, c.name), c.name, report);
    }
}
```

**Field-emission rules (locked to `blog.gen.ts`):**
- **Record:** `id: string;` first. For auth collections, the synthesized visible auth fields come next in the order `email`, `username`?, `verified` — **but** `blog.gen.ts`'s `User` shows `id, email, verified, name, created, updated` (no `username` because the blog users collection's auth identity is email-only and `username` is empty by default — the generator emits `username` only when present as a non-empty visible field; for the dating fixture `profiles` includes `username`). Then user fields in declared order, then `created: string; updated: string;`.
  > Implementation rule used by the plan: record fields = `id` + (auth ? synthesized visible auth fields) + user fields (declared order) + `created` + `updated`. Auth synthesized visible fields = `email` + `verified` (and `username` when the auth collection's `identityFields` include `username` OR is explicitly modeled). Plan 1 emits `email` + `verified` for the blog-shaped test and `email` + `username` + `verified` for the dating `profiles` (whose schema declares username via identityFields). The dating snapshot is the authority; the blog-shaped unit test asserts the `email`+`verified` subset.
- **Create:** required fields (no `?`) then optional fields (`?`); `id`/`created`/`updated`/read-only system fields excluded; `file`→`File | Blob`; select→union; relation→`string`/`string[]`. Auth collections additionally emit `email`, `password`, `passwordConfirm` (required) before user optionals (matches `UserCreate`).
- **Update:** `export type <Rec>Update = Partial<<Rec>Create>;` for base; auth: `export type <Rec>Update = Partial<Omit<<Rec>Create, "password" | "passwordConfirm">>;`.
- **Where:** for each non-readonly, non-file field emit `<name>?: <Ops> | <base>;` per kind — string→`StringOps | string`, number→`NumberOps | number`, bool→`boolean`, select→`EnumOps<Union> | Union`, autodate/date→`StringOps | string` (matches `created?: StringOps | string`), relation single→`string | RelOps | <TargetWhere>` (nested, when the target collection exists in `cols`), relation multi→`string | RelOps` (id-level only). Then `AND?: <Where>[]; OR?: <Where>[];`. **File fields are omitted from Where** (matches `blog.gen.ts`).
- **Relations / Expand:** `export type <Rec>Relations = { author: User; tags: Tag[] };` from relation fields (single→record, multi→record[]); `export type <Rec>Expand = "author" | "tags";` (omit entirely / emit `never` when no relations — for Plan 1 emit the union only when ≥1 relation; a relation-less collection's service uses no expand generic, see emitService).
- **Fields:** `export interface <Rec>Fields { <name>: TypedFieldExpr<<base>>; … }` for non-readonly, non-file fields (relation→`TypedFieldExpr<string>`, multi-relation→`TypedFieldExpr<string>` element type, matching `PostFields.tags: TypedFieldExpr<string>`).
- **Service:** the concrete `*Service` interface. Two shapes: **expandable** (has relations) uses the `getOne<K extends <Expand> = never>` generics + `WithExpand<…>` returns (mirrors `PostsService`); **non-expandable** uses the plain shape (mirrors `TagsService`). Auth collections additionally append `authWithPassword(identity, password): Promise<{ token: string; record: <Rec> }>;` (mirrors `UsersService`).
- **Meta:** `export const <colCamel>Meta: CollectionMeta = { name: "...", fields: { <name>: { type: "<fieldType>", multi?: true }, … }, fileFields: [...], expandable: [...], isAuth: <bool> };` — `fields` includes the same record fields as `meta` in `blog.gen.ts` (user fields + `created`/`updated`, plus synthesized auth fields for auth collections), each `{ type: "<schema FieldType tag>" }` with `multi: true` only for multi-value fields.
- **createClient:** the `db.*` map (each `makeRecordService(base, <meta>, relationResolver?) as unknown as <Service>`; auth collections `Object.assign`-graft `authWithPassword`), `realtime.*` map (`makeTypedRealtime<Rec, Where>(base.realtime, <meta>, relationResolver)`, one entry per collection that has a realtime alias — Plan 1 emits a realtime entry for every collection, matching the spec's `realtime.*` surface), `files` (the typed `url` wrapper reading `record[field]`), `authStore`/`send`/`fetch`. `authCollection` defaults to the first auth collection's name.

```zig
//! Every fragment mirrors clients/typescript/test/fixtures/blog.gen.ts.
const std = @import("std");
const schema = @import("../schema.zig");
const tt = @import("ts_type.zig");
const ident = @import("identifiers.zig");

const W = std.ArrayList(u8);

fn put(alloc: std.mem.Allocator, w: *W, s: []const u8) !void {
    try w.appendSlice(alloc, s);
}
fn putf(alloc: std.mem.Allocator, w: *W, comptime fmt: []const u8, args: anytype) !void {
    const s = try std.fmt.allocPrint(alloc, fmt, args);
    try w.appendSlice(alloc, s);
}

fn isReadOnlySystem(name: []const u8) bool {
    return std.mem.eql(u8, name, "id") or std.mem.eql(u8, name, "created") or std.mem.eql(u8, name, "updated");
}

/// The visible synthesized auth fields for an auth collection record, in
/// blog.gen.ts order. `username` is included only when `with_username` is set
/// (the dating `profiles` models it; the blog `users` does not).
fn appendVisibleAuthFields(alloc: std.mem.Allocator, list: *std.ArrayList(schema.Field), with_username: bool) !void {
    try list.append(alloc, .{ .id = "_email", .name = "email", .options = .{ .email = .{} } });
    if (with_username)
        try list.append(alloc, .{ .id = "_username", .name = "username", .options = .{ .text = .{} } });
    try list.append(alloc, .{ .id = "_verified", .name = "verified", .options = .{ .@"bool" = .{} } });
}

/// Whether an auth collection models `username` (its identityFields include it).
fn authHasUsername(c: schema.Collection) bool {
    if (c.type != .auth) return false;
    for (c.options.auth.identityFields) |f| if (std.mem.eql(u8, f, "username")) return true;
    return false;
}

/// The record fields, in emission order: id, (auth visible fields), user fields,
/// created, updated.
fn recordFields(alloc: std.mem.Allocator, c: schema.Collection) ![]schema.Field {
    var list: std.ArrayList(schema.Field) = .empty;
    try list.append(alloc, .{ .id = "_id", .name = "id", .options = .{ .text = .{} } });
    if (c.type == .auth) try appendVisibleAuthFields(alloc, &list, authHasUsername(c));
    for (c.fields) |f| {
        if (f.hidden) continue;
        if (isReadOnlySystem(f.name)) continue; // user-declared created/updated dedup
        try list.append(alloc, f);
    }
    try list.append(alloc, .{ .id = "_created", .name = "created", .options = .{ .autodate = .{} } });
    try list.append(alloc, .{ .id = "_updated", .name = "updated", .options = .{ .autodate = .{} } });
    return list.toOwnedSlice(alloc);
}

pub fn emitSelectUnions(alloc: std.mem.Allocator, w: *W, c: schema.Collection) !void {
    for (c.fields) |f| {
        if (f.options != .select) continue;
        const uname = try tt.selectUnionName(alloc, c.name, f.name);
        try putf(alloc, w, "export type {s} = ", .{uname});
        for (f.options.select.values, 0..) |v, i| {
            if (i != 0) try put(alloc, w, " | ");
            try putf(alloc, w, "\"{s}\"", .{v});
        }
        try put(alloc, w, ";\n");
    }
}

pub fn emitRecord(alloc: std.mem.Allocator, w: *W, c: schema.Collection) !void {
    const rec = try ident.recordName(alloc, c.name);
    try putf(alloc, w, "export interface {s} {{\n", .{rec});

        const ty = try tt.tsTypeOf(alloc, c.name, f);
        try putf(alloc, w, "  {s}: {s};\n", .{ f.name, ty });

pub fn emitCreate(alloc: std.mem.Allocator, w: *W, c: schema.Collection) !void {

    try putf(alloc, w, "export interface {s} {{\n", .{cn});
    if (c.type == .auth) {
        try put(alloc, w, "  email: string;\n  password: string;\n  passwordConfirm: string;\n");

pub fn emitWhere(alloc: std.mem.Allocator, w: *W, cols: []const schema.Collection, c: schema.Collection) !void {
    const wn = try ident.whereName(alloc, c.name);
    try putf(alloc, w, "export interface {s} {{\n", .{wn});
    // auth synthesized: email + verified are filterable; username when present.
    if (c.type == .auth) {
        try put(alloc, w, "  email?: StringOps | string;\n");
        if (authHasUsername(c)) try put(alloc, w, "  username?: StringOps | string;\n");
        try put(alloc, w, "  verified?: boolean;\n");
    }
    for (c.fields) |f| {
        if (f.hidden or isReadOnlySystem(f.name)) continue;
        switch (tt.kindOf(f)) {
            .file_name => continue, // files omitted from where
            .string => try putf(alloc, w, "  {s}?: StringOps | string;\n", .{f.name}),
            .number => try putf(alloc, w, "  {s}?: NumberOps | number;\n", .{f.name}),
            .boolean => try putf(alloc, w, "  {s}?: boolean;\n", .{f.name}),
            .unknown => try putf(alloc, w, "  {s}?: unknown;\n", .{f.name}),
            .select_union => {
                const u = try tt.selectUnionName(alloc, c.name, f.name);
                try putf(alloc, w, "  {s}?: EnumOps<{s}> | {s};\n", .{ f.name, u, u });
            },
            .relation_id => {
                const target = f.options.relation.targetCollectionId;
                if (!f.isMultiValue() and collectionExists(cols, target)) {
                    const tw = try ident.whereName(alloc, target);
                    try putf(alloc, w, "  {s}?: string | RelOps | {s};\n", .{ f.name, tw });
                } else {
                    try putf(alloc, w, "  {s}?: string | RelOps;\n", .{f.name});
                }
            },
        }
    }
    // autodate/date filterable created/updated when user-declared are already covered
    // above; the always-present `created` is added to match blog.gen.ts.
    try putf(alloc, w, "  AND?: {s}[];\n  OR?: {s}[];\n}}\n", .{ wn, wn });
}

pub fn emitRelations(alloc: std.mem.Allocator, w: *W, cols: []const schema.Collection, c: schema.Collection) !void {
    if (!hasRelations(c)) return;
    const rn = try ident.relationsName(alloc, c.name);
    try putf(alloc, w, "export type {s} = {{ ", .{rn});
    var first = true;
    for (c.fields) |f| {
        if (f.options != .relation) continue;
        if (!collectionExists(cols, f.options.relation.targetCollectionId)) continue;
        const tr = try ident.recordName(alloc, f.options.relation.targetCollectionId);
        if (!first) try put(alloc, w, "; ");
        first = false;
        if (f.isMultiValue()) try putf(alloc, w, "{s}: {s}[]", .{ f.name, tr }) else try putf(alloc, w, "{s}: {s}", .{ f.name, tr });
    }
    try put(alloc, w, " };\n");
}

    }
    try put(alloc, w, ";\n");
}

fn hasRelations(c: schema.Collection) bool {
    for (c.fields) |f| if (f.options == .relation) return true;
    return false;
}

pub fn emitFields(alloc: std.mem.Allocator, w: *W, c: schema.Collection) !void {

}
```

```zig
//! Reads @import("app").App.collections and emits a zbase.gen.ts.
const std = @import("std");
const zigbase = @import("zigbase");
const schema = zigbase.schema;
const emit = zigbase.codegen.emit;
const guards = zigbase.codegen.guards;
const ident = zigbase.codegen.identifiers;

const W = std.ArrayList(u8);

/// FNV-1a over a canonical serialization of the collections (declared order).
pub fn schemaHash(cols: []const schema.Collection) u64 {
    var h = std.hash.Fnv1a_64.init();
    for (cols) |c| {
        h.update(c.name);
        h.update("|");
        h.update(@tagName(c.type));
        for (c.fields) |f| {
            h.update("\x00");
            h.update(f.name);
            h.update(":");
            h.update(@tagName(std.meta.activeTag(f.options)));
            if (f.required) h.update("!");
            if (f.isMultiValue()) h.update("*");
            switch (f.options) {
                .select => |o| for (o.values) |v| {
                    h.update(",");
                    h.update(v);
                },
                .relation => |o| {
                    h.update("->");
                    h.update(o.targetCollectionId);
                },
                else => {},
            }
        }
    }
    return h.final();
}

fn section(alloc: std.mem.Allocator, w: *W, title: []const u8) !void {
    const line = try std.fmt.allocPrint(alloc, "\n// ---- {s} " ++ ("-" ** 4) ++ "\n\n", .{title});
    try w.appendSlice(alloc, line);
}

/// The pure generator core: collections -> full file text. Runs guards first.
pub fn generate(
    alloc: std.mem.Allocator,
    cols: []const schema.Collection,
    in_repo: bool,
    auth_collection: []const u8,
    client_name: []const u8,
) ![]const u8 {
    var report = guards.GuardReport{ .message = "" };
    try guards.checkOperatorNames(alloc, cols, &report);
    try guards.checkIdentifiers(alloc, cols, &report);

    var w: W = .empty;
    // header
    try w.appendSlice(alloc, try std.fmt.allocPrint(alloc,
        "// generated by zigbase — do not edit\n// schema-hash: {x:0>16}\n//\n", .{schemaHash(cols)}));
    try w.appendSlice(alloc,
        \\// In a consumer repo this file imports from "@zigbase/client" and
        \\// "@zigbase/client/typed". In this in-repo snapshot we import from the
        \\// package source so it typechecks against the working tree without a built dist.
        \\
    );
    try emit.emitImports(alloc, &w, in_repo);

    try section(alloc, &w, "Records");
    for (cols) |c| try emit.emitSelectUnions(alloc, &w, c);
    for (cols) |c| {
        try emit.emitRecord(alloc, &w, c);
        try w.appendSlice(alloc, "\n");
    }
    try section(alloc, &w, "Create / Update payloads");
    for (cols) |c| {
        try emit.emitCreate(alloc, &w, c);
        try emit.emitUpdate(alloc, &w, c);
    }
    try section(alloc, &w, "Where types");
    for (cols) |c| try emit.emitWhere(alloc, &w, cols, c);
    try section(alloc, &w, "Relations + expand keys");
    for (cols) |c| {
        try emit.emitRelations(alloc, &w, cols, c);
        try emit.emitExpandKeys(alloc, &w, c);
    }
    try section(alloc, &w, "Fluent accessor types");
    for (cols) |c| try emit.emitFields(alloc, &w, c);
    try section(alloc, &w, "Concrete service interfaces");
    for (cols) |c| try emit.emitService(alloc, &w, c);
    try section(alloc, &w, "Per-collection metadata");
    for (cols) |c| try emit.emitMeta(alloc, &w, c);
    try emit.emitRelationResolver(alloc, &w, cols);
    try section(alloc, &w, "Typed files surface");
    try emit.emitTypedFiles(alloc, &w, cols);
    try section(alloc, &w, "Typed realtime surface");
    for (cols) |c| try emit.emitRealtimeAlias(alloc, &w, c);
    try section(alloc, &w, "createClient");
    try emitClientFactory(alloc, &w, cols, client_name, auth_collection);

    return w.toOwnedSlice(alloc);

        \\  };
        \\  files: TypedFiles;
        \\  authStore: Client["authStore"];
        \\  send: Client["send"];
        \\  fetch: Client["fetch"];

        \\  fetch?: typeof fetch;
        \\  WebSocket?: typeof WebSocket;
        \\  authCollection?: string;
        \\}}
        \\

        \\export function createClient(url: string, opts: {0s}Options = {{}}): {0s} {{
        \\  const base: RealtimeEnabledClient = withRealtime(
        \\    baseCreateClient(url, {{
        \\      fetch: opts.fetch,
        \\      WebSocket: opts.WebSocket,
        \\      authCollection: opts.authCollection ?? "{1s}",
        \\    }}),
        \\  );
        \\
        \\  const typedFiles = makeTypedFiles(base.files);

        \\    db: {{
        \\

                \\      ) as unknown as {3s},

                .{ c.name, mc, resolver, svc }));
        }

    try w.appendSlice(alloc, "    },\n    realtime: {\n");

        \\    send: base.send.bind(base),
        \\    fetch: base.fetch.bind(base),
        \\  };
        \\}
        \\

fn emit_hasRelations(c: schema.Collection) bool {
    for (c.fields) |f| if (f.options == .relation) return true;
    return false;
}

const Args = struct {
    out: ?[]const u8 = null,
    api_prefix: []const u8 = "/api",
    check: bool = false,
};

fn parseArgs(alloc: std.mem.Allocator) !Args {
    var it = try std.process.argsWithAllocator(alloc);
    defer it.deinit();
    _ = it.next(); // exe name
    var args = Args{};
    while (it.next()) |a| {
        if (std.mem.eql(u8, a, "--out")) {
            args.out = try alloc.dupe(u8, it.next() orelse return error.MissingOutValue);
        } else if (std.mem.eql(u8, a, "--api-prefix")) {
            args.api_prefix = try alloc.dupe(u8, it.next() orelse return error.MissingApiPrefixValue);
        } else if (std.mem.eql(u8, a, "--check")) {
            args.check = true;
        } else {
            std.log.warn("gen_client: ignoring unknown arg '{s}'", .{a});
        }
    }
    return args;
}

/// Pick the auth collection name (first auth collection) + a client interface name.
fn authCollectionName(cols: []const schema.Collection) []const u8 {
    for (cols) |c| if (c.type == .auth) return c.name;
    return "";
}

pub fn main() !void {
    var gpa = std.heap.GeneralPurposeAllocator(.{}){};
    defer _ = gpa.deinit();
    const alloc = gpa.allocator();

    var arena = std.heap.ArenaAllocator.init(alloc);
    defer arena.deinit();
    const a = arena.allocator();

    const args = try parseArgs(a);
    const out_path = args.out orelse {
        std.log.err("gen_client: --out <path> is required", .{});
        return error.MissingOut;
    };

    const app = @import("app");
    const cols = app.App.collections;

    // in-repo import mode is selected when the snapshot lives under the package
    // tree; default to the published-subpath imports unless ZBASE_INREPO is set.
    const in_repo = std.process.hasEnvVarConstant("ZBASE_INREPO");
    const client_name = "ZbClient";

    const text = generate(a, cols, in_repo, authCollectionName(cols), client_name) catch |e| {
        // guard messages are printed via the report; re-run path for the message:
        var report = guards.GuardReport{ .message = "" };
        guards.checkOperatorNames(a, cols, &report) catch {};
        guards.checkIdentifiers(a, cols, &report) catch {};
        if (report.message.len > 0) std.log.err("{s}", .{report.message});
        return e;
    };

    if (args.check) {
        const existing = std.fs.cwd().readFileAlloc(a, out_path, 64 * 1024 * 1024) catch |e| {
            std.log.err("gen_client --check: cannot read '{s}': {s}", .{ out_path, @errorName(e) });
            return error.CheckReadFailed;
        };
        if (!std.mem.eql(u8, existing, text)) {
            std.log.err("gen_client --check: '{s}' is STALE — re-run gen-client to regenerate.", .{out_path});
            return error.Stale;
        }
        return;
    }

    if (std.fs.path.dirname(out_path)) |dir| std.fs.cwd().makePath(dir) catch {};
    try std.fs.cwd().writeFile(.{ .sub_path = out_path, .data = text });
    std.log.info("gen_client: wrote {s} ({d} bytes)", .{ out_path, text.len });
}
```

```zig
/// Build the pure-Zig client generator with `app_mod` (a module exposing
/// `pub const App = zigbase.App(.{...})`) + zigbase imported, and return the Run
/// step that emits `opts.out`. Consumers wire `zig build gen-client` to this.
pub fn genClientStep(
    b: *std.Build,
    zigbase_dep: *std.Build.Dependency,
    app_mod: *std.Build.Module,
    opts: GenOpts,
) *std.Build.Step.Run {
    const zigbase_mod = zigbase_dep.module("zigbase");
    return genClientStepInner(b, zigbase_mod, zigbase_dep.builder, app_mod, opts);
}

fn genClientStepInner(
    b: *std.Build,
    zigbase_mod: *std.Build.Module,
    zigbase_builder: *std.Build,
    app_mod: *std.Build.Module,
    opts: GenOpts,
) *std.Build.Step.Run {
    const target = b.graph.host;
    const gen_mod = b.createModule(.{
        // gen_client.zig lives in the zigbase package; resolve it via the dep builder's path.
        .root_source_file = zigbase_builder.path("src/codegen/gen_client.zig"),
        .target = target,
        .optimize = .Debug,
    });
    gen_mod.addImport("zigbase", zigbase_mod);
    gen_mod.addImport("app", app_mod);

    const gen_exe = b.addExecutable(.{ .name = "zbase-gen-client", .root_module = gen_mod });
    const run = b.addRunArtifact(gen_exe);
    run.addArg("--out");
    run.addArg(opts.out);
    run.addArg("--api-prefix");
    run.addArg(opts.api_prefix);
    if (opts.check) run.addArg("--check");
    if (opts.in_repo) run.setEnvironmentVariable("ZBASE_INREPO", "1");
    return run;
}
```

**Risks / decisions:**
- **How the generator exe imports the dating schema module.** The exe does `@import("app")`; the build binds an `"app"` import to a `*std.Build.Module` rooted at `fixtures/dating/schema.zig` (which exposes `pub const App`), and that app module imports `"zigbase"`. The codegen convention (`pub const App = zigbase.App(.{...})` at module scope) is a structural addition; current examples inline `zigbase.App(.{...}).runCli(init)` and must hoist to `pub const App` in Plan 2's golfsim refactor.
- **Exact `build.zig` wiring for `genClientStep`.** Two flavors: the public `genClientStep(b, zigbase_dep, app_mod, opts)` for external consumers (resolves the generator source via `zigbase_dep.builder.path("src/codegen/gen_client.zig")`), and the repo-local `gen-dating-client` step that uses the in-tree `zigbase_mod` + `b.path(...)` directly (no `b.dependency`). The generator exe is built for `b.graph.host` (it runs at build time), `.optimize = .Debug`. Open verification at execution: that `zigbase_dep.builder.path(...)` resolves the dependency's source tree (if not, expose the generator source via a dependency module/named lazy path) — flagged for the implementer; the repo-local step (which the dating golden depends on) uses `b.path(...)` and is unaffected.
- **How the generated file is included in the TS typecheck.** The snapshot + `typecheck.ts` live under `clients/typescript/test/codegen/dating/`; the package tsconfig already includes `test`, so `npx tsc --noEmit` compiles both. The generated imports use in-repo relative paths (`../../../src/...`) under `ZBASE_INREPO` so it typechecks against the working tree without a built `dist` — mirroring `blog.gen.ts`. The published-subpath import mode (`@zigbase/client`, `@zigbase/client/typed`) is emitted when `ZBASE_INREPO` is unset (for real consumers).
- **Auth `username` synthesis.** The comptime `App.collections` spec does NOT carry the runtime-injected auth system fields (`schema.injectAuthFields` runs at provisioning, not in `buildCollections`), and `identityFields` defaults to email-only and is not surfaced per-collection in the comptime literal. Decision: the generator synthesizes the **full visible auth surface** `email`+`username`+`verified` for every `.auth` collection (the non-hidden subset of `schema.authSystemFields()`), so the dating `profiles` record/where/fields/meta/create include `username`. The blog-shaped unit tests assert only the `email`+`verified` subset they care about (and `blog.gen.ts`'s `User` omits `username` — a divergence accepted because the SP2.1a hand-authored fixture predates this rule; the generator's authoritative output is the dating snapshot, and Plan 2 reconciles the blog fixture if it is ever regenerated rather than hand-authored). This is the single intentional deviation from `blog.gen.ts` and is isolated to the auth-username field.
- **`makeFilesSurface` generalization.** `blog.gen.ts` inlines a single-collection `files: { url(record, field) { ... record[field] ... } }`. The generator emits a named `makeFilesSurface(typedFiles)` returning a `TypedFiles` object with one `url` overload per file-bearing collection (profiles.avatar, photos.image). For a single file collection this is byte-equivalent to the inline form; the named helper scales to N. Asserted by the Task-4 emit test (the `record[field]` lookup) and the Task-8 typecheck.
- **Zig 0.16 std.Io / ArrayList API.** Emit-helpers use `std.ArrayList(u8)` with the explicit-allocator API (`.empty`, `appendSlice(alloc, …)`, `toOwnedSlice(alloc)`) per the 0.16 migration; file IO uses `std.fs.cwd().readFileAlloc`/`writeFile`.
