# Plan — Theme B2: TTL records (`.ttl_field`) — issue #81

Spec: `docs/superpowers/specs/2026-06-27-theme-b2-ttl-design.md`.
Strict TDD: each task writes a failing test first, runs the suite to see it fail,
implements, sees it pass, commits.

Verify gate after every task:
`mise exec zig@0.16.0 -- zig build test --summary all` → judge by the
`Build Summary: N/N tests passed` line (the `failed command:` line is spurious).

## Task 1 — Collection option + persistence (`schema.zig`)

1. Test (fails): `ttl_field` round-trips through `optionsToJson`/`optionsFromJson`.
2. Implement:
   - Add `ttl_field: ?[]const u8 = null` to `CollectionOptions`.
   - `optionsToJson`: when `c.options.ttl_field != null`, put a
     `"ttl": {"field": "<name>"}` object into the root.
   - `optionsFromJson`: parse it back (it lives at root, not under `auth`, so move
     the early `auth`-missing `return` to not drop it).
3. Commit.

## Task 2 — Comptime lowering + validation (`provision.zig`)

1. Test (fails): a collection with `.ttl_field` naming a `date` field compiles and
   sets `options.ttl_field`.
2. Implement in `buildCollection`: `if (@hasField(S, "ttl_field"))` read it, find
   the named field, `@compileError` if absent or not `.date`/`.autodate`, else set
   `col.options.ttl_field`.
3. Commit.

## Task 3 — The GC routine (`records.zig`)

1. Test (fails): `gcExpiredRecords` deletes a past row, keeps a future row, leaves
   a non-TTL collection untouched.
2. Implement `pub fn gcExpiredRecords(alloc, w) !usize` per the spec (validate
   identifiers, DELETE with `strftime` predicate, sum `changesCount`).
3. Commit.

## Task 4 — Internal-job mechanism (`scheduler.zig` + `framework.zig`)

1. Test (fails): `concatJobs` combines two tables (lengths + names).
2. Implement `scheduler.concatJobs`.
3. Wire `framework.zig`: rename `jobs`→`user_jobs`, add `internal_jobs` gated on
   comptime-any-ttl, `pub const jobs = concatJobs(...)`, define `ttlGcJob`, thread
   `has_ttl` into `ServeOpts`, add the startup one-shot sweep.
4. Commit.

## Task 5 — Docs + example + changelog

1. `docs/framework.md` + `site/src/content/docs/framework.md`: a TTL subsection in
   §8 (collections), and mention the internal `_ttl_gc` job in §7.
2. `examples/golfsim`: add a TTL collection demonstrating `.ttl_field`.
3. `changelog.d/theme-b2-ttl.md` (`### Features`).
4. Build the site (`cd site && npm run build`) and the example.
5. Commit.
