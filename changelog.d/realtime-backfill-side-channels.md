### Security

- `GET /api/realtime/backfill` no longer reveals how many writes a caller may not see. Process-local (`-Drealtime-backfill=true`) cursors are now encrypted and authenticated like the durable journal's, so their bytes no longer end in the collection's write count (#496). On both stores, `limit` now counts authorized items: a page skips entries the caller may not see and keeps scanning, and `hasNext` is true only when another authorized item follows, so the page count and `hasNext` no longer grow with other users' or tenants' writes (#501). A durable request examines at most 4096 journal entries; only builds that raise `-Dreplay-max-entries` above that can end a page early. Durable checkpoints issued before the upgrade stay valid.
