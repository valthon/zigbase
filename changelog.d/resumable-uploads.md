### Features
- Add opt-in, principal-bound resumable file uploads for existing records, with configurable session/memory/chunk/expiry budgets, authorization and field-size checks before payload reservation, and commit-time authorization through the normal file mutation path. Completed and failed acknowledgements retain session slots until original expiry; cancellation only accepts receiving sessions. This bounded network-resume workflow is process-local and fully buffered, not restart-durable or cross-instance storage. The REST reference and protocol guide explain retry windows, quota sizing, and shared-capacity fairness limitations.
