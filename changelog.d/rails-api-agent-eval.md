### Fixes

- `rails2zb extract` now reports a public access rule that was written as an expression. The
  per-action rule form the guide teaches writes `create = @public` inside an `expression` decision,
  and `report.json`'s `publicRules` counted only decisions whose *choice* was `public` — so a bundle
  granting anonymous create reported no public rules at all, which is the one number an operator
  checks before deciding the surface is closed. It is read from the emitted schema now, and still
  names source tables rather than renamed collections.

### Internal

- Added the graded `rails-api` agent-eval scenario over the frozen Rails 8.1 snapshot, with a
  deterministic grader for completion, rules_locked, tests_green, and deployed, a positive workspace
  generated by running the real converter, and one isolated failure per grade. The scenario pins
  byte-identical copies of both the converter and the snapshot, so an eval cannot grade against a
  tool nobody ships. No release evidence has been recorded for it yet.
- Eval fixture workspaces are no longer collected by pytest. Each carries the `tests/test_migration.py`
  the grader runs inside the workspace, and two scenarios shipping that filename collided on import.
