### Breaking
- ZigBase consumers now require Zig 0.17.1. The library, server, examples, and build tooling use its current APIs; use `debug`, `safe`, `fast`, or `small` for optimization flags. C declarations come through ZigBase’s pinned official translate-c dependency without extra consumer build steps.

### Fixes
- Cached build configuration tracks Git provenance, native-version headers, and embedded asset inputs so rebuilt binaries report the current commit and assets.

### Internal
- Ported the zap fork and runner diagnostics to Zig 0.17.1. Issue #261 still reproduces; the shipped simple runner remains in use and continues to reject real failures.
