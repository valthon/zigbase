### Internal

- Made the query lexer/parser/compiler self-freeing (allocator ownership contract 1). `compiler.compile` now builds its throwaway SQL fragments on a function-local scratch arena and dupes only the escaping `where_sql` and each bound param's `.text` onto the caller allocator (which also removes the prior aliasing of params into the lexer's un-escape buffer); its signature is unchanged, so no caller (`records.list`, `rules.compileGuard`) changed. `parser.parse` gains a recursive `freeNode` (and errdefers so a mid-parse error frees the partial AST), and `lexer.lex` gains `freeTokens`. Behavior is unchanged — the emitted SQL and param values are byte-identical (asserted by the existing compile tests). All `query/lexer.zig` (5) and `query/parser.zig` (9) tests drop their arena masking (both allowlist entries removed); `query/compiler.zig`'s tests now drive lex/parse/compile on the raw leak detector and free the returned graph, so `compile`'s own allocations are leak-checked, though the file keeps its allowlist count because each test still needs a setup arena for the DB-backed collection + joiner (the joiner's per-call scratch is a separate, still-pending migration).
