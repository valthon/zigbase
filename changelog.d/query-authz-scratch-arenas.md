### Internal

- Made the four guarded-query authorization "bool executors" self-freeing (allocator ownership contract 1): `policy.authorizes`, `policy.matchesRule`, `rules.matches`, and `records.guardPasses` each build their throwaway compiled guard (its WHERE fragment, joins, bound params and prepared-statement scratch) on a function-local arena and free it, so they are leak-correct under any allocator instead of only when the caller passes a request/delivery arena. This is a correctness/contract change, not a runtime memory change: every in-tree call site already passes an arena — the scratch was reclaimed with that arena and still is (an arena-backed `deinit` frees no capacity back) — so the fix removes a latent leak for a non-arena (general-purpose) caller and, above all, lets the tests verify these paths under the raw leak detector. On the back of it, the realtime-hub `shouldDeliver` delivery tests (public/ability/macro/subscription-filter/owner-scoped-delete/tenant-scoping/expired-identity), the `rules.matches` guarded-select test, and the `policy.authorizes` parity test drop their arena masking; the allocator-contract allowlist shrinks (`rules.zig` removed, `policy.zig` 16→15, `realtime/hub.zig` 11→4), with the remaining masked tests' justifications updated to name the separate un-migrated root cause each still waits on (the returned `Guard` graph with no `deinit`, the `records.list` query scratch, the colcache lease).
