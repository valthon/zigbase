### Features

- Per-device session REST + SDK for `.session_store = .table`: `GET /api/collections/:col/auth/sessions` (`{"items":[…]}`, newest first, `is_current` marked), `DELETE …/auth/sessions/:sid` (`204`; non-owned/absent ids are an indistinguishable `404`), and `DELETE …/auth/sessions` ("log out everywhere", works in **both** session-store modes, clears the session cookies). In the default `.epoch` mode the per-device routes answer `404`. `@zigbase/client` gains `listSessions()`, `revokeSession(id)`, `revokeAllSessions()` and the `SessionInfo` type. The `sessions` auth-method slug is now reserved.
