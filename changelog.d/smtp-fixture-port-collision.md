### Internal

- Fixed a latent port collision in the live SMTP-over-TLS test fixture (`tests/smtp`). It chose its SMTP and HTTP ports with two sequential `bind(0)`-then-close calls, which returns each port to the ephemeral pool before it is used, so both roles could be handed the *same* number: `aiosmtpd` bound it, `zigbase serve` then failed to bind, and the test's HTTP request reached the SMTP listener — surfacing three steps later as `BadStatusLine: 220 ... Python SMTP`. Both ports are now reserved together, with every socket held open until all are chosen, which removes the duplicate rather than making it rarer. The readiness guard was also complicit: it only opened a TCP connection, so an SMTP listener satisfied "zigbase serve did not come up"; the HTTP role now requires a real HTTP response, failing at the point of failure instead of three steps later.
